## Getting Started

### Preview Locally

1. Open `portfolio/portfolio.html` directly in your browser.
2. Or serve the folder locally using Python:

```powershell
cd c:\Users\Admin\Documents\intern\portfolio
python -m http.server 8081
```

Then open `http://localhost:8081/portfolio.html` in your browser.

## Customization
